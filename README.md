# Amey Clinic — site institucional

Projeto acadêmico de interface para apresentação de uma clínica odontológica, com conteúdo visual e seções sobre serviços e atendimento.

## Como visualizar

Não é necessário instalar dependências. Abra [`index.html`](./index.html) em um navegador para visualizar o site.

## Arquivos

- `index.html` — página principal e estilos da interface.
- Imagens na raiz do repositório — identidade visual e imagens utilizadas na página.
